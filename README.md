# Mon Portfolio

## Description
Après une première formation HTML/CSS, je réalise mon portfolio moi-même.

## Fonctionnalités
- contient une galerie de qualités
- possède un en-tête avec navigation
- possède une section À propos qui me décrit globalement
- possède un formulaire de contact
- possède un pied de page

## Technologies
HTML, CSS

## Ce que j'ai appris
Les fondations du HTML et du CSS : sémantique, box model, Flexbox, Grid, responsive.

## Comment lancer le projet
ouvrir index.html dans le navigateur (ou via live server)
